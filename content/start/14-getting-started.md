# How do I reopen Getting started?

Open your profile menu in the console and choose **Getting started**. It restores the welcome path chooser so you can set up a task, connect an agent, or use shared skills. The choices reflect your current organization access.

## Continue saved work

Choose the path for the result you need. Existing setup progress is useful: return to the saved task or connection instead of creating another one. If the chooser reports a loading error, use **Reload starting path**.

If an expected choice is absent, check the organization selected and ask an admin to review your access. [Missing pages and actions](/start/missing-access) explains the presets.
