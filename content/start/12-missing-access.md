# Why can’t I see a console page or action?

Your organization access determines which console pages and actions appear. Ask an admin to check your presets and membership expiry in **Settings → People**. A missing action can be intentional: reviewing corrections does not by itself grant access to task standards, releases, or skill publishing.

## Check the organization and access

Make sure the intended organization is selected. A person can belong to several organizations with different access in each. If you followed an invitation to a particular item, the invitation’s presets must include that kind of work.

An admin can combine presets. For example, **Reviewer** plus **Task observer** lets a colleague review corrections and read task results. **Skill contributor** can save drafts, while **Skill manager** can publish them. **Evidence auditor** receives metadata rather than full event content.

Presets apply across the organization, not to a single task or skill. Admins have full organization access through the admin role. [See all presets](/start/who-does-what) or [invite a colleague](/console/settings/invite-a-colleague).
