# Review work from your team

An invitation can open an exact approval, comparison, agent run, or skill version. Accept it with the invited email, sign in, and open the assigned organization. Your access determines the actions available.

| Work | Access | Next action |
| --- | --- | --- |
| Held agent action | Agent approver | Inspect the tool and arguments, then approve or reject |
| Answer correction, label, or saved step | Reviewer | Read the evidence and record your review |
| Skill draft | Skill contributor or Skill manager | Save changes; a manager can publish |
| Recorded history | Evidence auditor | Read metadata; this preset does not expose event content |

Open **Inbox** for the overview, then **Open review queue** for individual items. A task’s **Review** tab also shows its proposed answer corrections. A Reviewer preset alone does not grant the Tasks browser; use the queue or ask for Task observer access as well.

**Your first result:** a saved review or approval decision linked to the work you inspected. Approving an agent call does not execute it; the agent runtime must resume the same step.

If the work moved, your access expired, or you see an access error, ask the inviter to check the destination and your [presets](/start/who-does-what). Do not request a runtime key to work around a missing human permission.
