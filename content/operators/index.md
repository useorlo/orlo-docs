# Operate Orlo

Self-hosting lets your organization run Orlo in its own environment. fineSample supplies the licensed deployment package, supported version information, and installation instructions. The platform source repository is private; [the agent SDKs are public](/open-source).

:::cards
- [Prepare a deployment](/operators/deploy) Plan public addresses, provider access, storage, and verification.
- [Operate and recover](/operators/operate) Plan upgrades, backups, restore checks, and ongoing administration.
:::

Use the deployment guide supplied with your release for privileged setup, secret configuration, and recovery commands. These public pages describe the preparation and operational outcomes to verify.
