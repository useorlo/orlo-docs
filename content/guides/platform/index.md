# Platform

Orlo Platform is the full managed control plane for domain intelligence.

It gives teams one operating surface for the full loop:

```text
Define -> Evaluate -> Deploy -> Govern -> Observe -> Improve
```

## Product Surfaces

- **Mission Control and dashboard**: health, deployments, evaluations, approvals, feedback pressure, monitoring, sessions, credentials, users, and API keys.
- **Control-plane API**: task, dataset, evaluation, deployment, inference, feedback, retrieval, routing, monitoring, and agent-governance endpoints.
- **Gateway**: hosted authentication, tenant context, API keys, RBAC, scopes, rate limits, licensing, and audit events.
- **Workers**: async evaluation, document ingestion, embedding, scoring, archiving, and drift-related work.
- **Data layer**: org-scoped persistence, task versions, deployment snapshots, inference logs, trace samples, feedback, retrieval chunks, and credentials.
