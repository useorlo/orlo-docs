# Evidence

*Who can do this: Evidence auditors read history and metadata; admins read everything, including event content.*

**Evidence** is one page, filtered by task and date, for the person who has to answer “what happened?”

## What is on record

| For | The record holds |
| --- | --- |
| Every answer | The release and model that produced it, the task version, the result of each rule, token usage, and the passages it drew on |
| Every comparison | The candidates, the dataset version, the rubric and the judge, each score with its interval, and every answer behind the scores |
| Every release | The task version, the model, the strategy, the comparison that chose it when there was one, who made it, and when it was live |
| Every agent step | The step as the agent reported it, the decision, the rules that matched, the approval and who decided where a person was involved |
| Every skill version | Who published, who retired and why, which tasks pinned it, which runs declared it, and each retrieval by an AI tool |
| Every organization change | Keys created and rotated, people invited and removed, connectors connected and disconnected, signals dismissed |

## Reading it

Pick a task and a range. The page lists answers, comparisons, releases, approvals, and audit events in time order, and each opens to its full record. A release’s row links to the comparison that chose it; an answer’s row links to the release and, for a task with sources, to the passages.

## Boundary

The record is written once and not edited by the product. Orlo records evidence; it does not issue sign-off, and it is not a certification.
